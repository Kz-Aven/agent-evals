# 任务执行链记录提示词（Agent Execution Trace）

> 用途：工作流 A / C 的记录规范。执行用户任务时按本文件记录可观察的执行轨迹，供后续 Agent Eval 使用。

---

## 一、记录原则

1. **只记录可观察信息**：用户 Query、Agent 输出、Skill/Tool 调用、参数、工具结果、状态变化、错误与恢复、最终答案。
2. **不输出、不模拟、不推断模型隐藏的思维链（Chain of Thought）**。
3. **边执行边记录**，禁止事后凭记忆补写或美化已发生的失败。
4. **结果真实**：工具或数据不可用时写明限制，禁止编造 Tool Result。
5. **关键数字保留原值**：条数、金额、时间戳、百分比、字段名都要能复算。
6. **敏感信息脱敏**：人名、公司名、客户名、表 ID、内部域名等，写入前替换为占位符。

---

## 二、必须记录的 10 类信息

1. 用户 Query
2. Agent 当前任务状态
3. Skill 选择（含未命中说明）
4. Tool Call
5. Tool 参数
6. Tool Result
7. 错误信息
8. Retry / Recovery
9. 下一步动作
10. 最终输出

---

## 三、推荐格式

```markdown
# User Query

> 用户的原始请求原文（含交付物、格式、时间范围等约束）

# Execution Trace

## Step 1

Action:
这一步要做什么

Skill:
命中的技能名；未命中写"未命中，本步未调用"

Tool:
工具名 × 调用次数

Arguments:
关键参数，需可复核

Result:
工具真实返回的关键数据、条数、数值与结论

## Step 2

Action:
...

Skill:
...

Tool:
...

Arguments:
...

Result:
...

（按实际步骤继续）

# Error / Recovery

| # | Error | Recovery |
|---|-------|----------|
| 1 | 错误原文 | 恢复动作与结果 |

# Final Answer

交付给用户的最终结论与交付物清单

# Execution Summary

- Total Tool Calls:
- Total LLM Calls:
- Errors:
- Retries:
- Final Status:
```

---

## 四、字段填写细则

| 字段 | 填写要求 |
| --- | --- |
| Action | 一句话说明意图，例如"加载分析技能""按员工维度聚合呼叫量" |
| Skill | 写实际加载的技能；加载失败写明失败原因与后续重试结果 |
| Tool | 工具名 + 次数，例如 `bash (python 统计)` × 3、`query_filter` × 2 |
| Arguments | 查询条件、路径、时间区间、抽样方式、模型参数等，保留原始取值 |
| Result | 保留关键返回值：命中条数、字段、聚合结果、文件产出与大小；不要只写"成功" |
| 下一步动作 | 仅在需要说明判断依据时单列，例如"因无真实图片，改用 AI 生成场景图" |

---

## 五、执行中的强制动作

- **每次关键 Tool Result 后校验**：该结果是否支撑下一步。不支撑时换参数、换工具或换数据源，并把判断写进 Result 或下一步动作。
- **失败先记录后重试**：先记 `Error` 原文，再记 `Recovery`（有限重试 / 换工具 / 换数据源 / 降级方案），重试次数有限，禁止死循环。
- **数据缺口显式声明**：查询为空、字段缺失、无权限的表，都要写明并说明替代口径。
- **收尾必填两段**：`Final Answer` 与 `Execution Summary`（Tool / LLM 调用数、错误数、重试数、最终状态）。

---

## 六、脱敏约定

写入执行链前替换以下内容（脱敏后仍要保持可读与可复核）：

| 类型 | 替换为 |
| --- | --- |
| 人名（员工/客户/销售） | 张三、李四、王五、赵六…… |
| 公司名 / 品牌名 / 客户名 | xx公司、xx品牌、xx客户 |
| 内部系统、平台、数据源 | xx数据平台、xxCRM |
| 数据表 ID、记录 ID | `<表ID-已脱敏>` |
| 竞品名 | 竞品A、竞品B |
| 内部域名、OSS 链接 | `<内部链接-已脱敏>` |
| 技能/工具名 | 保留原名（不属于敏感信息） |

---

## 七、输出

任务完成后，将完整执行链输出为 **`xxx任务-任务执行链.md`**，其中 `xxx任务` 为任务的简短命名（如 `8月最差销售分析`、`使用知识库材料生成PPT`）。
